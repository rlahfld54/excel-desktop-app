# 2026-05-18 작업 정리

이 문서는 오늘 진행한 Excel 자동화 데스크톱 앱 UI 작업을 처음 보는 사람도 이해할 수 있도록 정리한 기록입니다.

## 프로젝트 방향

현재 프로젝트는 React, Vite, Electron 기반의 데스크톱 스타일 Excel 자동화 도구입니다.

목표는 단순한 랜딩 페이지나 템플릿 대시보드가 아니라, 사무 사용자가 Excel/CSV 파일을 열고 데이터를 확인한 뒤 자동화 작업을 실행할 수 있는 실무형 작업 공간을 만드는 것입니다.

핵심 사용 흐름은 다음과 같습니다.

1. Excel 또는 CSV 파일을 업로드하거나 엽니다.
2. 데이터를 표 형태로 확인합니다.
3. 필터, 정렬, 열 설정, 찾기/바꾸기, 검증, 고정, 내보내기 같은 표 작업을 수행합니다.
4. 데이터 정리, 코드 매핑, 중복 검사, 백업, 보고서 생성 같은 자동화 작업을 실행합니다.
5. 작업 로그, 오류, 경고, 최근 파일, 백업 상태를 한 화면에서 확인합니다.

Dashboard 화면을 기존 템플릿 카드 중심 화면에서 Excel 자동화 작업 공간 형태로 변경했습니다.

주요 변경 파일은 다음과 같습니다.

Dashboard 화면에는 다음 요소가 들어갔습니다.

  - 자동화 상태
  - 검증 결과
- 중앙 Excel 스타일 데이터 표
  - 시트 탭
  - 필터, 정렬, 열, 찾기/바꾸기, 검증, 고정, 내보내기 버튼
  - 행 번호
  - 거래일, 거래처, 품목 코드, 품목명, 수량, 단가, 금액, 검증, 담당자 컬럼
  - 정상, 확인 필요, 중복 의심 상태 뱃지

## 2차 작업 구현 방식

새 공통 컴포넌트를 추가했습니다.

- src/pages/WorkspaceModulePage.jsx

이 컴포넌트는 각 메뉴 페이지가 공통적으로 사용하는 업무 화면 구조를 담당합니다.

공통 화면 구성은 다음과 같습니다.

- 페이지 제목
- 설명 문구
- 주요 액션 버튼
- 요약 지표 카드 3개
- 업무 목록 테이블
- 오른쪽 보조 패널

각 페이지는 직접 UI를 많이 들고 있지 않고, moduleKey만 넘겨서 자기 화면을 표시합니다.

예시:

- RecentTasksPage.jsx는 recentTasks 설정을 사용합니다.
- FileManagerPage.jsx는 fileManager 설정을 사용합니다.
- DataTablePage.jsx는 dataTable 설정을 사용합니다.
- SystemStatusPage.jsx는 systemStatus 설정을 사용합니다.

이 방식의 장점은 다음과 같습니다.

- 모든 메뉴가 비슷한 품질의 실제 화면을 빠르게 가질 수 있습니다.
- 추후 실제 API, 파일 데이터, 자동화 상태를 연결할 때 한 곳에서 구조를 개선하기 쉽습니다.
- 깨진 placeholder 문구를 제거하고, 메뉴마다 의미 있는 한글 UI를 표시할 수 있습니다.

## 현재 주의할 점

아직 커밋하지 않은 변경 사항이 있습니다.

현재 남아 있는 작업은 크게 두 종류입니다.

1. 메뉴별 업무 화면 구현 작업
   - 이번에 새로 만든 WorkspaceModulePage와 18개 메뉴 페이지 연결 작업입니다.

2. 참고자료.txt 수정
   - 이 파일은 이전부터 수정되어 있던 파일입니다.
   - Dashboard 커밋 때도 일부러 커밋에 포함하지 않았습니다.

다음 커밋을 만들 때는 참고자료.txt를 포함할지 제외할지 먼저 확인하는 것이 좋습니다.

## 다음 작업 제안

다음 단계로 자연스러운 작업은 다음 중 하나입니다.

1. 메뉴별 화면 작업을 하나의 커밋으로 저장합니다.
2. 각 메뉴 화면을 더 구체화합니다.
3. 실제 Excel/CSV 파일 업로드와 표 데이터 연결을 시작합니다.
4. 자동화 실행 버튼과 로그 패널을 실제 상태와 연결합니다.
5. Vite define 설정의 process.env 경고를 정리합니다.
