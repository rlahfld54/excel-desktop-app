# Excel Desktop App 브랜드 가이드

## 브랜드 방향

Excel Desktop App은 반복되는 엑셀 업무를 더 안정적이고 재사용 가능한 흐름으로 바꾸는 데스크톱 작업 공간입니다. 브랜드는 화려한 대시보드보다, 매일 엑셀 파일을 다루는 사람이 믿고 사용할 수 있는 실무형 도구처럼 느껴져야 합니다.

핵심 인상은 다음과 같습니다.

- 차분함: 복잡한 데이터를 다루더라도 화면은 안정적으로 보여야 합니다.
- 정확함: 검증, 매핑, 백업, 보고서 생성처럼 신뢰가 중요한 작업을 지원합니다.
- 실용성: 설명보다 작업 흐름과 실행 가능성이 먼저 보여야 합니다.

## 로고 컨셉

로고는 세 가지 의미를 결합했습니다.

- 스프레드시트 그리드: 행과 열로 구성된 엑셀 작업의 기본 구조를 나타냅니다.
- 자동화 실행 마크: 반복 작업을 실행하고 워크플로우를 돌리는 기능을 상징합니다.
- 에메랄드 작업 프레임: 데이터 정리, 검증 완료, 안정적인 업무 환경을 연상시키는 브랜드 컬러입니다.

작은 사이드바, 브라우저 탭, 향후 패키징된 데스크톱 앱 아이콘에서도 알아보기 쉽도록 단순한 형태로 설계했습니다.

## 로고 파일

- 앱 메인 로고: `src/images/logo.svg`
- 브라우저 favicon: `src/favicon.svg`
- 빌드 및 데스크톱 앱 아이콘 원본: `public/icon.svg`

SVG를 원본 자산으로 사용합니다. 나중에 데스크톱 패키징에서 `.ico`, `.icns`, 여러 크기의 PNG가 필요해지면 `public/icon.svg`에서 내보내면 됩니다.

## 컬러 시스템

주요 포인트 컬러는 에메랄드/틸 계열입니다.

- Accent 500: `#10B981`
- Accent 600: `#059669`
- Accent 700: `#047857`
- Deep Foundation: `#022C22`
- Soft Surface: `#ECFDF7`

포인트 컬러는 다음 위치에 사용합니다.

- 주요 실행 버튼
- 활성화된 사이드바 메뉴
- 선택된 탭과 캘린더 상태
- 진행률과 실행 상태 표시
- 테이블 row hover
- 클릭 가능한 UI의 은은한 hover 배경

포인트 컬러는 사용자가 “어디를 보고 있고, 무엇을 실행할 수 있는지” 이해하도록 돕는 색입니다. 페이지 전체 배경처럼 넓은 영역을 채우는 용도로는 사용하지 않습니다.

## 브랜드 톤

제품 문구는 간결하고, 실무적이며, 신뢰감 있게 작성합니다.

권장 문구:

- 반복되는 엑셀 업무를 자동화하세요.
- 정리, 검증, 매핑, 보고서 생성을 하나의 작업 공간에서 처리하세요.
- 안정적인 스프레드시트 업무를 위한 데스크톱 앱입니다.
- 수동으로 반복하던 엑셀 작업을 재사용 가능한 워크플로우로 바꾸세요.

피해야 할 문구:

- 과장된 생산성 표현
- “마법처럼”, “한 번에 완벽하게” 같은 모호한 표현
- 핵심 UI 안에서 지나치게 가벼운 농담
- 데이터 처리 과정을 불명확하게 만드는 표현

## 짧은 제품 소개

Excel Desktop App은 엑셀 파일 정리, 데이터 검증, 코드 매핑, 백업, 보고서 생성을 한 곳에서 처리할 수 있는 데스크톱 작업 공간입니다. 반복되는 스프레드시트 업무를 더 쉽게 실행하고, 더 안정적으로 관리할 수 있도록 돕습니다.

## 조금 더 긴 소개 문구

Excel Desktop App은 매일 반복되는 엑셀 업무를 체계적인 워크플로우로 바꾸는 데스크톱 앱입니다. 파일 관리, 데이터 테이블 확인, 코드 매핑, 중복 검사, 백업, 복원, 보고서 생성, 작업 이력 관리를 한 화면 흐름 안에서 연결합니다. 사용자는 수동으로 반복하던 작업을 더 빠르게 실행하고, 검증 결과와 자동화 상태를 더 명확하게 확인할 수 있습니다.

## UI 사용 규칙

- 주요 실행 버튼은 `btn btn-primary`를 사용합니다.
- 보조 버튼은 `btn btn-secondary`를 사용합니다.
- 아이콘 버튼의 hover 상태는 연한 accent 배경을 사용할 수 있습니다.
- 성공, 경고, 오류 상태 색상은 의미를 유지합니다.
- 초록색이라고 해서 모든 상태를 accent로 바꾸지 않습니다. 브랜드 컬러와 상태 컬러는 역할이 다릅니다.
- 포인트 컬러는 “선택됨”, “실행 가능”, “현재 위치”를 보여주는 데 우선 사용합니다.

## 로고 사용 규칙

권장:

- 흰색, 연한 회색, 어두운 중립 배경 위에 사용합니다.
- 로고 주변에 충분한 여백을 둡니다.
- 앱 아이콘은 128x128 SVG를 기준으로 축소해 사용합니다.
- 작은 크기에서는 심볼만 사용합니다.

금지:

- 로고 비율을 임의로 늘리거나 줄이지 않습니다.
- 일부 요소만 다른 색으로 바꾸지 않습니다.
- 복잡한 이미지 배경 위에 바로 올리지 않습니다.
- 특별한 플랫폼 요구가 없는 한 그림자나 외곽선을 추가하지 않습니다.

## 한 줄 소개

반복되는 엑셀 업무를 자동화하고, 데이터 검증부터 보고서 생성까지 한 곳에서 관리하는 데스크톱 작업 공간.

## 태그라인 후보

- 반복되는 엑셀 업무를 더 안정적으로.
- 엑셀 파일에서 워크플로우까지.
- 수동 엑셀 작업을 실행 가능한 자동화로.
- 정리, 검증, 백업, 보고서를 한 작업 공간에서.
