# 화면 역할

## Dashboard

역할:

- 오늘 처리할 파일과 검증 상태를 한 화면에서 보여준다.
- 업로드, 검증, 오류 처리, 저장, 자동화 실행의 시작점이다.

주요 기능:

- 현재 파일 요약
- 검증 결과 요약
- Excel 스타일 테이블
- 행 선택
- 선택 행 상세
- 승인/보류/수정 필요 처리
- 자동화 큐
- 로그
- 현재 작업 저장
- 샘플 파일 내보내기

## 프로젝트

### 최근 작업

최근 실행한 자동화, 검증, 보고서 생성 작업을 확인한다.

### 파일 관리

업로드한 Excel/CSV 파일, 고정 파일, 프로젝트 폴더를 관리한다.

### 자동화 작업

정리, 매핑, 중복 검사, 보고서 생성 규칙을 관리한다.

### 보고서 생성

검증 완료 데이터를 PDF/XLSX 보고서로 만드는 작업을 관리한다.

## 데이터

### 데이터 테이블

업로드 데이터를 표 형태로 확인하고 필터링한다.

### 코드 매핑

거래처명, 제품명, 코드 흔들림을 표준 코드로 연결한다.

핵심 기능:

- 거래처 자동 추천 매핑
- 제품 자동 추천 매핑
- 별칭 승인
- 미매핑 목록

### 중복 검사

거래일, 거래처 코드, 제품 코드, 수량, 금액 기준으로 중복 후보를 찾는다.

### 활동 로그

검증, 저장, 보고서, 발송 준비, 백업 이벤트를 확인한다.

## 백업

### 로컬 백업

SQLite, 스냅샷, 원본 파일, 정제 JSON 캐시를 로컬에 백업한다.

### 클라우드 백업

초기에는 화면 초안만 유지한다. 실제 동기화는 MVP 후순위다.

### 복원

로컬 백업에서 작업 상태를 복원한다.

## 요청 센터

### 요청 대시보드

거래처 확인 요청 대상과 패키지 준비 상태를 한눈에 확인한다.

### 연락처 목록

거래처별 이메일, 카카오톡 연락처, 선호 채널을 관리한다.

개인 담당자보다 부서 단위 연락처를 우선한다.

### 문구 템플릿

부드러운 협조 요청 문구를 관리한다.

문구는 책임 추궁보다 자료 확인과 협조 요청에 초점을 둔다.

### 발송 패키지

앱이 직접 발송하지 않고 발송 준비물을 만든다.

생성물:

- 거래처별 PDF
- 거래처별 XLSX
- send_list.csv
- 카톡 복사용 문구
- 첨부 폴더

### 발송 이력

외부 도구로 발송한 후 사용자가 수동으로 완료/회신/재요청 상태를 기록한다.

## 설정

### 사용자 설정

시작 화면, 표시 방식, 테마, 알림을 관리한다.

### 저장 설정

자동 저장, 원본 보존, 저장 전 검증 정책을 관리한다.

### 동기화 설정

로컬 우선 정책을 기본으로 한다. 클라우드는 백업 또는 공유가 필요할 때만 사용한다.

### 보안

암호화, 권한, 감사 로그 정책을 관리한다.

## 관리자

### 작업 이력

사용자와 시스템 작업 이력을 확인한다.

### 시스템 상태

파일 인덱서, 자동화 엔진, 백업 서비스, 동기화 상태를 확인한다.

### 캐시 관리

임시 업로드, 미리보기, 인덱스 캐시를 정리한다.

## 화면 설계 원칙

- 첫 화면은 랜딩 페이지가 아니라 작업 화면이어야 한다.
- 반복 업무자는 큰 홍보 문구보다 바로 눌러야 할 버튼과 상태를 원한다.
- 카드 남발보다 표, 상태, 로그, 액션을 우선한다.
- 오른쪽 또는 하단 보조 패널은 정보를 압축해서 보여준다.
- 버튼은 누르면 상태나 로그가 바뀌어야 한다.
