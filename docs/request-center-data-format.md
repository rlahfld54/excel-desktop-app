# 요청 센터 데이터 준비 기준

요청 센터는 직접 메일을 보내기 전에 연락처, 문구, 첨부 파일, 발송 목록을 한곳에서 준비하는 영역이다.

## 연락처 CSV

실제 연락처를 가져올 때 권장하는 CSV 컬럼은 아래와 같다.

| 컬럼 | 필수 | 예시 | 설명 |
| --- | --- | --- | --- |
| 거래처코드 | 권장 | CUST-001 | 기준 데이터의 거래처 코드 |
| 거래처명 | 필수 | 한빛유통 | 화면 표시와 매칭 보조값 |
| 부서 | 권장 | 정산팀 | 거래처 내부 담당 부서 |
| 담당자명 | 권장 | 홍길동 | 수신자 이름 |
| 이메일 | EMAIL 채널 필수 | settle@example.com | send_list.csv 생성 기준 |
| 전화번호 | 선택 | 010-0000-0000 | 카카오/전화 확인용 |
| 선호채널 | 필수 | EMAIL | EMAIL, KAKAO 중 하나 |
| 상태 | 권장 | ACTIVE | ACTIVE, HOLD |
| 메모 | 선택 | 월마감 담당 | 운영 메모 |

## 문구 템플릿 변수

현재 기본 템플릿은 아래 변수를 사용한다.

| 변수 | 예시 | 설명 |
| --- | --- | --- |
| `{{customer_name}}` | 한빛유통 | 거래처명 |
| `{{closing_month}}` | 2026-05 | 마감월 |

문구는 책임 추궁보다 협조 요청에 가깝게 유지한다. 총무팀이 최종 검수자 역할을 하더라도, 거래처 또는 내부 부서에 보내는 문장은 확인과 정정 요청 중심으로 작성한다.

## 발송 패키지 구성

한 개의 발송 패키지는 특정 마감월의 요청 묶음이다.

| 구성 | 예시 |
| --- | --- |
| 패키지명 | REQ-202605-SAMPLE |
| 출력 폴더 | exports/request/202605 |
| 발송 대상 | 거래처별 연락처 |
| 첨부 PDF | exports/request/202605/CUST-001.pdf |
| 첨부 XLSX | exports/request/202605/CUST-001.xlsx |
| 발송 목록 | send_list.csv |

초기 MVP에서는 앱이 직접 대량 메일을 보내지 않는다. 대신 PDF/XLSX, 제목, 본문, 수신자 목록을 준비하고 사용자가 Outlook, Gmail, 카카오톡 등 외부 도구에서 확인 후 보내는 방식이 안전하다.

## 다음 구현 기준

1. 연락처 CSV 가져오기
2. 발송 패키지별 `send_list.csv` 내보내기
3. 거래처별 검수 결과 PDF/XLSX 생성
4. 발송 완료/회신/종료 상태 수동 체크
5. 패키지 생성 시 누락 이메일과 첨부 누락 경고
