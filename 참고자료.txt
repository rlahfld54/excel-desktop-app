## Current Product Direction

Build a desktop-style Excel automation workspace.
The first screen should feel like a practical work tool, not a landing page.

Core mental model:

- Open or upload Excel/CSV files.
- Inspect and edit data in a spreadsheet-like grid.
- Run automation tasks such as cleanup, code mapping, duplicate checks, validation, backup, and report generation.
- Show task progress, logs, errors, warnings, and recent files in the same workspace.
- Keep the UI understandable for non-developer office users.

## Visual Reference Notes

The reference image suggests this layout:

- Left sidebar grouped by Project, Data, Backup, Settings, Admin.
- Top toolbar with Upload, Save, Undo, Redo, Run Automation, autosave status, search, notifications, and account controls.
- Main tabbed data workspace with an Excel-like table.
- Table actions: Filter, Sort, Columns, Find & Replace, Validate, Freeze, Export.
- Right workspace explorer for recent files, pinned files, backup versions, and project folders.
- Bottom panels for logs and automation status.
- Bottom status bar for active file, row/column counts, selected cell, aggregate values, encoding, auto-save, and sync state.

## Implementation Bias

- Prefer reusable workspace panels over one-off dashboard cards.
- Keep feature modules easy to swap because the plan may change.
- Use the existing React/Vite/Electron setup.
- Use existing packages where useful: xlsx, exceljs, ag-grid, better-sqlite3.
- Fix Korean menu text encoding before polishing navigation.
