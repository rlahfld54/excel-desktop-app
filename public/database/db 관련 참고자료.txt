화면 데이터는 이렇게 매핑하면 돼.

보고서
→ report_jobs.report_name

데이터 소스
→ report_jobs.data_source_name

형식
→ report_jobs.output_format

최근 생성
→ report_jobs.generated_at

상태
→ report_jobs.status

출력 옵션은 이렇게 저장돼.

표지 포함
→ report_output_options.include_cover

오류 행 강조
→ report_output_options.highlight_error_rows

담당자별 분리
→ report_output_options.split_by_department
※ 네 방향이면 담당자별보다 부서별 분리가 더 좋아서 컬럼명은 split_by_department 추천

클라우드 백업 첨부
→ report_output_options.attach_cloud_backup
